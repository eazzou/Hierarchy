How the scales work

Each size comes from the formula base size × ratio raised to a scale step. H4 uses step 1, H3 step 2, H2 step 3, and H1 step 4. Emphasis and links share the body size but use weight and styling to stand out. CSS overrides Bootstrap’s default heading sizes.
